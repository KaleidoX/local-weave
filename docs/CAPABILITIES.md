# 当前能力矩阵

[文档目录](README.md) · [测试与证据范围](TEST_REPORT.md) · [已知限制](KNOWN_LIMITATIONS.md)

状态描述实际实现与限定验证，不能从构造器、feature 或依赖名称推断生产兼容性。当前源码交付不包含已发布 crate/npm 或跨平台预编译包。

| 能力                                           | 当前实现与验证边界                                                                                                                                                                                                                                                              |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 单连接 SQLite Session、authorizer、原子 outbox | Linux Rust 公开 API 实测；仅 SDK 自有受控写连接                                                                                                                                                                                                                                 |
| 因果 DAG、完整行 MV register、显式 resolve     | 真实 SQLite/公开 API 与排列、重复、回滚、依赖和分叉测试                                                                                                                                                                                                                         |

| 内嵌 SQLite                                    | bundled 3.53.2 已验证；明确 opt-in                                                                                                                                                                                                                                              |
| 普通持久数据库路径                             | 三个引擎 profile 的公开 consumer 持久性、拒绝零副作用、exact outbox、恢复新 incarnation 已通过                                                                                                                                                                                  |
| 原始 `file:` URI                               | Store/Sdk open 及 backup/restore 派生数据库路径在文件操作前拒绝；不开放 URI/memory/VFS                                                                                                                                                                                          |

| Google Drive                                   | `DEFERRED / PROTOTYPE_NOT_ACCEPTED`；仅保留记录原型，三项未解决反例；附件未实现                                                                                                                                                                                                 |
| 本地灾备/共享快照/恢复                         | 一致快照、私有缓存隔离、exact bytes 保留、新 incarnation；存在裸相对目标限制                                                                                                                                                                                                    |
| CLI `lfs`                                      | Linux 源码构建及真实 JSON/API 闭环；doctor 动态检查，diagnostics 静态元信息                                                                                                                                                                                                     |

| Browser                                        | 不在当前范围                                                                                                                                                                                                                                                                    |
| 签名/E2EE/多人权限/自动远端 GC                 | 未实现                                                                                                                                                                                                                                                                          |

真实 WebDAV 的限定结果：经宿主明确接受非 loopback HTTP 风险，以 native Operator 完成 64 KiB 对象 write/read/stat/list、三设备 typed/conflict/resolve/no-echo、五个包枚举和 raw envelope 校验；测试对象 DELETE 返回 204，后续 PROPFIND 返回 404。严格便利工厂仍拒绝非 loopback HTTP。该结果不是通用云兼容性、Node、全部 SQLite profile、附件或长期可靠性的资格；不公开 endpoint 或认证信息。

内存 transport、故障注入和合成 HTTP 代理属于 MODEL；rclone 属于本地独立服务。它们验证协议或失败边界，不能替代真实服务验证。详细复现命令和既有结果摘要见 [TEST_REPORT](TEST_REPORT.md)。
